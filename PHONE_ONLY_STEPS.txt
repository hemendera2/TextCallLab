KALLVO — PHONE INSTALL CHECKLIST (CURRENT)
========================================
IMPORTANT: There is no reason to install Termux, Git, GitHub CLI, llama.cpp, sherpa-onnx,
Python or Gradle on your Samsung phone to use KALLVO. Those are developer build
dependencies fetched and compiled automatically in GitHub Actions.

ONE-TIME OWNER SETUP BEFORE THE FINAL APP INSTALL
1. Do not uninstall an older installed KALLVO: uninstall erases privately stored
   Qwen GGUF, neural voice packs, encrypted tasks and preferences.
2. Android only upgrades apps signed by the same certificate. Current old CI
   debug APKs were signed with temporary runner keys, so they cannot be promised
   an in-place data-preserving upgrade. Installing another debug APK repeatedly
   does NOT solve the underlying signing problem.
3. For future updates, configure GitHub Actions stable signing ONCE, using the same
   private JKS keystore and the FOUR encrypted repository secrets:
     KALLVO_ANDROID_KEYSTORE_B64
     KALLVO_ANDROID_STORE_PASSWORD
     KALLVO_ANDROID_KEY_ALIAS
     KALLVO_ANDROID_KEY_PASSWORD
   The keystore must stay PRIVATE and safely backed up by the owner. Never commit
   it or paste a password into public chat/issues. A pre-existing installed APK
   needs its ORIGINAL signing identity to allow a direct update.
4. Use the newest successful Android Actions build for the exact intended commit.
   Download ONLY "KALLVO-stable-signed-APK" for owner installation; an artifact
   labelled "KALLVO-UNSTABLE-debug-do-NOT-upgrade" is a code/test artifact only.
5. Verify APK file integrity and signer identity before installing.
6. On first app use: one-time app-internal AI model (~484 MB) and neural voice
   (~125 MB) downloads with mobile-data costs disclosed. Then models remain in
   app-private storage and should not be downloaded again for app restarts.
7. Check Assistant > Tasks, voice sample, Hindi recognition availability,
   navigation and model benchmark on the actual Samsung phone.

NO FALSE CLAIMS
- Current ordinary Android app DOES NOT certify audio interception or injection
  for Jio/carrier calls. Samsung Bixby Text Call is separate from KALLVO's
  selected neural voice; consenting A52s real-call testing is essential.
- Successful GitHub Actions, Android Lint and static tests do NOT replace
  hands-on device acceptance for latency, Hindi intelligibility, battery,
  incoming-call compatibility and permissions.
- The original ZIP + Termux + gh repo create steps were for an OLD prototype
  and are not part of the current user installation workflow.
